# Backlog del Sprint 1

| Prioridad | Historia de usuario | Valor | Criterio de aceptación |
|---|---|---|---|
| 1 | Como comprador quiero ver eventos disponibles para elegir uno. | Permite descubrir la oferta. | Se muestran nombre, fecha, lugar, precio y disponibilidad. |
| 2 | Como comprador quiero ver el detalle de un evento para decidir si compro. | Evita compras mal informadas. | Muestra descripción, fecha, precio y entradas restantes. |
| 3 | Como comprador quiero seleccionar una cantidad de entradas para crear una orden. | Convierte interés en compra. | No permite superar inventario. |
| 4 | Como comprador quiero simular el pago de una orden para confirmar la compra. | Demuestra el flujo completo. | La orden queda confirmada cuando el pago se aprueba. |
| 5 | Como administrador quiero registrar un evento para ponerlo a la venta. | Alimenta el catálogo. | Valida nombre, fecha, capacidad y precio. |

## Cómo llevarlo a Trello

Crear las listas **Backlog**, **Sprint 1**, **En progreso**, **En revisión** y **Hecho**. Crear una tarjeta por historia. Añadir prioridad, responsable, criterios de aceptación y una etiqueta para cada tipo de trabajo: UX, frontend, backend, pruebas o documentación.
